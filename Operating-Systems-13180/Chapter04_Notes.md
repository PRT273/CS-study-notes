第四章 进程/线程调度



4.1 线程调度的基本概念



在多道程序环境下，系统中往往同时存在多个进程或线程，

但 CPU 在任一时刻只能执行一个。



调度（Scheduling） 的作用就是：



决定在多个就绪进程（或线程）中，

哪一个获得 CPU 以及获得多长时间。



调度是操作系统实现并发和提高系统性能的核心机制。





4.2 调度 Harmonies（调度层次）



从系统角度看，调度通常分为以下**几个层次**：



高级调度（作业调度）：



高级调度的主要任务是：

决定哪些作业进入系统

控制系统中作业的数量

高级调度常见于批处理系统中，在现代交互系统中较少涉及。



中级调度（内存调度）



中级调度主要负责：

决定进程是否被挂起或恢复

实现内存与外存之间的调度



其目的是：

提高内存利用率

控制系统负载



低级调度（进程 / 线程调度）



低级调度是最常见、最重要的调度形式，主要负责：

在就绪进程（线程）中选择一个执行

实现 CPU 的分配

本章讨论的调度，主要指低级调度。





4.3 **调度的目标与准则**



评价调度算法的好坏，通常从以下几个方面考虑：

CPU 利用率：CPU 忙碌时间所占比例

系统吞吐量：单位时间内完成的进程数

周转时间：进程从提交到完成的总时间

等待时间：进程在就绪队列中等待的时间

响应时间：从请求到首次响应的时间



不同系统侧重点不同：

批处理系统关注吞吐量

分时系统关注响应时间





4.4 **抢占式调度与非抢占式调度**



非抢占式调度

非抢占式调度的特点是：

进程一旦获得 CPU，便一直执行

直到进程结束或发生阻塞



优点：

实现简单

开销小



缺点：

响应时间长

不适合交互系统





抢占式调度

抢占式调度的特点是：

操作系统可以强制暂停正在运行的进程

将 CPU 分配给其他进程



优点：

响应快

系统公平性较好



缺点：

实现复杂

上下文切换开销较大

现代操作系统大多采用抢占式调度。





4.5 常见的调度算法



**先来先服务调度（FCFS）**

基本思想：

按进程到达就绪队列的顺序分配 CPU



特点：

实现简单

对长进程有利



缺点：

短进程等待时间长

容易产生“护航效应”





短作业优先调度（SJF）



基本思想：

优先调度运行时间最短的进程



优点：

平均等待时间最小



缺点：

难以准确预知运行时间

可能导致长作业饥饿





时间片轮转调度（RR）



基本思想：

为每个进程分配一个固定时间片

时间片用完后，进程被放回就绪队列末尾



特点：

公平、响应快。



时间片大小的影响：

过大 → 退化为 FCFS

过小 → 上下文切换开销大





优先级调度



基本思想：

为进程分配优先级

优先级高的进程先执行



问题：

可能导致低优先级进程长期得不到 CPU（饥饿）



常见解决方法：

优先级老化（Aging）





4.6 多级队列调度

多级队列调度将就绪队列划分为多个队列：

不同队列使用不同调度算法

队列之间存在固定的优先级关系



特点：

灵活

适用于复杂系统



缺点：

设计和维护复杂





4.7 多级反馈队列调度（MLFQ）



多级反馈队列调度的核心思想是：

根据进程的运行行为动态调整优先级

不需要事先知道进程运行时间



特点：

兼顾响应时间和吞吐量

广泛应用于现代操作系统





4.8 线程调度



在引入线程后，调度的对象可以是：

进程

线程



在大多数现代系统中：

**线程是 CPU 调度的基本单位**。



线程调度的优势包括：

切换开销小

并发度高

更好地利用多核处理器





4.9 上下文切换（Context Switch）



4.9.1 上下文切换的概念



上下文切换是指 CPU 从一个进程（或线程）切换到另一个时：

保存当前运行实体的状态

恢复下一个运行实体的状态





4.9.2 上下文切换的开销



上下文切换会带来一定的系统开销，包括：

保存和恢复寄存器

切换内存映射

刷新缓存（部分情况）



因此，调度算法设计需要权衡：

响应性和系统开销





4.10 本章小结



本章主要介绍了：

调度的基本概念和层次

调度的目标与评价指标

抢占式与非抢占式调度

常见调度算法

线程调度与上下文切换



进程与线程调度是操作系统实现并发和性能优化的关键机制，

**也是后续 同步、死锁、多处理器调度 等内容的基础**。
